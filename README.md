# AI Content Production Pipeline

## Project goal
Build and evaluate a repeatable workflow for AI-assisted short-form video production.

## Current status
Early-stage prototype. The workflow and performance metrics will be documented as testing progresses.

## Planned workflow
1. Develop a content concept and script.
2. Generate AI-assisted visual assets.
3. Edit selected assets into a short video.
4. Review quality and consistency.
5. Record production time, cost, output volume and published views.
